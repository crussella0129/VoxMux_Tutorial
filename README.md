# VoxMux
The Local AI Multiplexer - chat with a model via llama.cpp or pytorch (directly from safetensor or gguf), without a browser

## Layout

- [`RECIPE.md`](RECIPE.md): step-by-step instructions, in words, for writing the app by hand as a Python exercise.
- [`answer_key/`](answer_key/): the finished minimal app to compare against. Run it with `pip install -r answer_key/requirements.txt` then `python answer_key/app.py`.
